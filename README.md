# Color Palette Generator - Create, Save, Share & Export High‑Quality Palettes

Live demo: generate harmonious color palettes, lock colors, preview themes, and export PNG/JSON — optimized for designers and developers. Learn sharing, mobile tips, and undo/redo workflow.

---

#### 🔗 Live demo
https://universal-coding-experiments.github.io/color-palette-generator/

---

## ✨ Features
- Modes: Random, Analogous, Complementary, Triadic, Monochrome.
- Size control: Slider to pick 2–8 colors.
- Locking: Lock individual swatches to preserve them.
- Live preview: Instant updates, gradient bar, and hover preview with contrast.
- Save & manage: Save to localStorage, load, delete (undoable).
- Share: Shareable URL encoding colors, name, and model.
- Export: High‑quality PNG and JSON export; CSS variables output.
- Mockups: Live theme previews (header, button, card) using palette variables.
- Undo/Redo: Step backward and forward through edits.
- Mobile friendly: Responsive layout, touch targets, preview toggle.
